## Patterns

- **Live session crash recovery:** while `isActive`, `liveSessionDraft.ts` debounces an AsyncStorage snapshot; on next cold start `LiveSessionResumeGate` offers **Resume** (restores store + pushes `/live-session`) or **Discard** (clears draft; does not PATCH mid-session route to Fly)
- **Compass liveness:** `liveSessionStore` treats the device compass as available only while usable `watchHeadingAsync` readings keep arriving (`COMPASS_STALE_AFTER_MS`). `watchHeadingAsync` keeps firing during magnetic interference / lost calibration but `resolveCompassHeading` rejects those readings, so a latched flag would pin `currentHeading` for the whole session; once stale, heading falls back to the GPS bearing and keeps the last value rather than blanking the arrow beam. The EMA runs on its own accumulator so readings held back by the notify/rate gates still advance the filter (slow steady turns used to leave the dial sitting still). Heading and position watches carry generation tokens so a superseded in-flight `startLocationWatching` (double AppState `active`) cannot leak a second subscription.
- **Live map marker is never gated on basemap readiness:** in `LiveSessionMapWebView` only the route source/layer waits on `map.isStyleLoaded()`; `syncMarkers` and the camera always run. A slow raster source (Esri satellite/hybrid) can hold `isStyleLoaded()` false long enough to freeze the pin otherwise.
- **Track tab** (`BottomNavBar` on home, sessions, account, notifications): active live session → `/live-session`; otherwise → `/session-setup` (pre-track `/tracker-paywall` hidden)
- **Session start → tracker minimize:** photo submit after form starts the session and replaces → `/live-session?from=onboarding`; tracker back/minimize immediately `dismissTo('/')` (clears setup stack; no collapse wipe) so Home (and every other bottom-nav screen) shows the minimized live pill while GPS/timer keep running. Track on Shop/Sessions/Account/etc. resumes `/live-session` when active (never reopens setup).
- **Shop tab** → `/shop`; **Sessions tab** → `/sessions-list`; **Profile tab** → `/account`
- **Tab switches** use `animation: 'none'` (instant); tour and submission-confirmation Go Home use `?enter=fade` + home opacity fade; empty cart / order history **Browse Shop** use `?enter=fade` into `/shop`; hierarchical pushes keep the default slide
- **Guide navigation:** Continue uses `router.push`. **Previous** always `replace`s to the named prior step (`goToSessionSetupGuide` / `goToSessionSetupStep2`…`Step5` / `goToSessionFreeHour` / `goToPreviousFromSessionSetupCamera` / `goToPreviousFromSessionSetupComplete`) with the shared guide `pop` animation — never `router.back()`, which jumps to Home after Skip or location auto-skip collapses the stack. - Volunteer Home is gated on a **registered** Supabase session (not anonymous). Spec: [volunteer-auth.md](../specs/volunteer-auth.md).

- Phone country picker uses Unicode flag emojis + dial codes from `constants/countries.ts` (no flag asset package); US formatting applies for US/CA only; modal scrim is static while only the sheet springs up/down (`animationType: none`)
- Phone step collects **full legal name** first (required, min 2 chars; immutable after setup) then phone; legal name is saved to `onboardingStore` and shown in the home greeting

- Phone step uses `KeyboardAvoidingView` + tap-outside / drag-to-dismiss so Continue stays reachable above the phone-pad keyboard
- `CheckoutScreen` form fields chain focus via `TextInput` refs + `returnKeyType="next"` / `onSubmitEditing` (Full Name → Street → City → State → ZIP → Card Number → Expiry → CVV → Name on Card); Name on Card is `returnKeyType="done"` and submits the order. CVV is capped at 3 digits (`maxLength={3}`, `slice(0, 3)`).

- **Live tracker location pill:** `LiveSessionScreen` absolutely centers the pill in the navbar row (back + compass stay tappable at `zIndex: 1`); divider uses symmetric `marginHorizontal: 10`; weather icon matches location pin at 18px; place label truncates when the 188px pill overflows.

## Policies

- **Never call an argument-less `liveSessionStore` getter from a render body.** React Compiler (`app.json` → `experiments.reactCompiler`) sees zero dependencies on helpers that read module state and caches the first result for the component's life. `getLiveSessionMapCenter()` did this in `LiveSessionMapNative` and froze the tracker map on its "Getting precise location…" spinner whenever the screen mounted before the first GPS seed; it has been removed. Read `useLiveSession()` and derive, or add a reactive mirror field to the store (as `checkpointDueOrGrace` does).
- **Minimum age is 13 (COPPA under 13).** `AccountDetailsScreen` uses `isUnderMinimumAge` from `constants/ageGate.ts` (`ageFromBirthday(birthday) < 13`). Under-age: `clearCreateAccountDraft()` + `clearOnboardingSignupData()` then `router.replace('/under-age')` — **no Supabase account is created**. Age 13+ creates the auth session then continues to `/creating-account` → `/how-it-works`.
- **Session checkpoint camera is 18+.** Ages 13–17 can track GPS and hours (`photosEnabled: false`) but skip `/photo-capture`, checkpoint UI/alerts, and onboarding/session-setup camera prompts. Birth month/year persist in `user_metadata` (`birth_month`, `birth_year`) and `onboardingStore`.
- **Universal privacy defaults:** notification preferences default off (opt-in); no nudge copy in notification settings. No teen privacy tier in app.
- **Privacy Policy copy** lives in `features/figma-screens/content/privacyPolicyContent.ts` (index + four detail routes: what we collect / how we use / who we share / how we protect). Effective July 20, 2026; last updated September 1, 2026. Index footer matches Account: “CleanUp Give Back is a 501(c)(3) nonprofit corporation.” Draft product copy pending counsel review.
- **Do not add new screens to the prototype.** New screens are registered in `frontend/design/figma/manifest.yaml` and implemented as native RN routes under `src/app/`.
- The HTML prototype (`/prototype/[screen]`) is **frozen** — it continues to run for Expo Go demos but receives no new features.
- Native production screens live under `src/app/<routeKey>.tsx` following Expo Router file-based conventions. Use the `routeKey` from `manifest.yaml` as the filename.
- When a native screen ships, set its `status` to `implemented` in `manifest.yaml` and remove its entry from `HTML_MAP`.
