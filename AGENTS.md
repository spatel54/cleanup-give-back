- Users under 13 are blocked from the app with privacy-law messaging on the gate screen.
- Mobile profile shows **Court Ordered** vs **Volunteer** tag under the name with distinct colors; admin volunteer tag gets a green border like the court-ordered tag.
- Admin UI and copy are written for operator Admin (account chrome, welcome text, “Admin can…” flows); email compose uses CC/BCC, font/size/color toolbar, schedule send, and everyday-language template chips (not `{{brackets}}`). List multiselect uses a right-side Select control that swaps to red Delete (with selected count) plus gray Cancel and per-row checkboxes (Company codes, Sessions). Mobile Letters is a library of PDFs already downloaded (not every approved session); separate card rows with search/sort filters; floating **Export** FAB instead of Select (empty list → Download Service Record; otherwise multi-select → **Export all** date-range / combined-PDF **Share** / **Cancel**). Volunteer-facing surfaces (emails, shop shipping labels, assistance) use `support@example.org` and **Clean Up Give Back** branding — never the admin's name.
- Tote bag color variants should use earth/ocean labels in data/backend (not green/blue UI labels). Earth-and-Ocean split swatch sits last (Figma `1344:169`: top green `#009540` / bottom blue `#3B82F6`, thin black line overshooting left and right).
- Admin sessions/users must stay on real Supabase data (no fixture fallback); service-role reads must be cookie-free so signed-in admin JWTs do not empty RLS-scoped lists.
- On admin session walking-path maps, use square rounded photo thumbnails that open a lightbox (not circular pins).
- Live and replay maps must not draw a path until real GPS movement exists (no synthetic stationary line); when OS reports `speedMps === 0`, treat sub-gate jitter as stationary; replay also collapses when span < ~8 m or recorded distance < 0.01 mi — prefer tightening append gates over lowering the collapse span much under ~5–6 m; Recent Cleanups feed map cards must match session detail (no path without movement), show a static snapshot of the session’s actual cleanup location (not a generic US-centered map), and include a location marker on the card. Session-detail route replay uses a taller card with a bottom-right location pin to re-center; the live tracker location pin also reorients heading.
- Admin session empty photo state should show four placeholders (Selfie → Progress → Selfie → Progress), not three; pre-session photo cancel → Session Setup (filled form), mid-session cancel → live tracker. Checkpoint **selfie + rear** count as two submitted photos and both thumbnails should show; header is **Checkpoint photos**. Live tracker checkpoint and timer cards collapse with a small expand chevron; the timer chevron sits in a quiet centered Apple-style notch just outside the bottom of the timer card; compact checkpoint also shows the yellow next-photo-due bar. Tapping anywhere on the live minimized widget opens the live tracker. iOS Live Activities use primary green (photo overdue: red) with a lighter tinted body, bundled Noto Sans + IBM Plex fonts (no Sanchez), and a black CUPGB logo; Lock Screen photos-on is mi | TIME | next photo with a centered Strava-style hero time (~40pt SemiBold vs ~20pt sides) plus a **time** unit label, side stats hugging the edges, and the green/red bar flush to the body (no seam; **16pt** gap under the bar so the 40pt hero does not crowd it); photos off is mi | TIME (same hero); Photo due is mi | TIME | remaining (10-minute grace countdown on the right; sits at 0:00 after grace); checkpoint windows do not auto-rollover — a new 30:00 next-photo timer starts only after selfie + progress photos are submitted; Dynamic Island compact shows logo left and time right; the widget timer must stay in sync with the live tracker. Button radii: big full-width CTAs `radius.md` (16), inline/dense actions `radius.sm` (8), chips and circular FABs `radius.full`. Orientation “One hour” graphic stays below the title/subtitle (no overlap). After Allow location, 18+ always see Allow camera (including session-setup) and the progress pills count that step.
- Order History and Donation History hide the bottom tab navbar.
- Mobile shop selected chips and cart accents use tertiary brand color, not gray or lime. Product images viewer uses bottom tap-to-select thumbnails (not arrows) with the full image visible, not cropped. Tracker checkout shows **Trash Cleanup Kit** in a primary-green card (image left, white semibold title + “Free with tracking access”); kit-remove copy refers to vest, not tote. Home **Your Impact** favors a visual Recent Cleanups feed with a concise period summary (not a dense stats grid); month/year pickers are list-only with no type-to-search. Service-hours chart: dynamic min/hr y-axis ticks (no top unit label), horizontal grid only, integer bar labels, flat (non-gradient) bars flush at the baseline. ## Learned Workspace Facts

- Production admin console lives in `admin-web-app/` (renamed from `web-app`); legacy `admin/` is archived — keep `admin/db/*.sql` for Supabase migrations only.
- Admin place search: event address autocomplete uses Photon first with Google Places when a key is available; US heatmap/fullscreen map search uses Census (streets) + Photon (places) in parallel with Nominatim as backup (Google Places optional).
- Transactional email for admin/mobile flows uses Resend (`RESEND_API_KEY` in env; never commit secrets). Volunteer templates: Sanchez for headers and buttons, Noto Sans for body; CTA buttons primary green with a stroke (not lime); current-hours in white; icons/logos/GIFs must load consistently; sender avatar is the filled CUPGB mark (white on primary green).
- Volunteer profile “Miles Walked” sums `sessions.distance_miles` for approved sessions only (same scope as Approved Hours).
- `admin-web-app` deploys on Vercel (Next.js App Router + TypeScript + Tailwind + shadcn-style `components/ui`); live session services run from `backend/sessions/` on Fly. iOS TestFlight builds run from `frontend/` via EAS or Fastlane: `fastlane ios build` (local `eas build --platform ios --profile production --local`), `fastlane ios submit` (newest IPA), `fastlane ios beta` (build + submit); when cloud upload fails/stucks or monthly iOS quota is exhausted, use those local lanes or `eas build --platform ios --profile production --local` then `eas submit --path <ipa>`. iOS Live Activity UI lives in `frontend/targets/live-session-widget/` (bundled brand fonts; requires a native rebuild); browser stand-in is `preview.html`.
- Admin top period bar is Today / Month / Year / All / Custom (no 30-day option). Payments: Month = last 6 months, Year = last 6 years; Sessions/Orders/Feedback Month uses a rolling ~30-day window.
- Mobile session checkpoint photos should persist lat/long so admin walking-path maps can pin them by capture location. Camera zoom runs through `resolveZoomPlan` (`frontend/src/lib/cameraZoom.ts`) on top of `frontend/patches/expo-camera+17.0.10.patch` — an absolute `zoomFactor` prop plus device zoom-range reporting, applied by `postinstall` and requiring a native rebuild (see [ADR-007](docs/adr/ADR-007-patched-expo-camera-zoom.md)). Never map labelled optical factors onto the stock 0–1 `zoom` prop: its exponent base is `activeFormat.videoMaxZoomFactor` and is unreadable from JS. **No iPhone has a front ultra-wide**, so without a wider lens 0.5× and 1× are both the sensor's full frame (no digital crop); with an optical ultra-wide, 0.5×→1× is the real wide-lens hand-off. Selfie locks to that full-sensor framing (internal 0.5× / `min` zoom) with **no zoom UI** and explicitly selects the widest front lens via `findWidestFrontLens`; rear defaults to **0.5×** with the full 0.5×–5× control. Regenerate the patch on any expo-camera upgrade.
- CARTO **raster** basemap tiles (Home Recent Cleanups `SessionMapSnapshot`, event location WebView pins) require `EXPO_PUBLIC_CARTO_BASEMAP_API_KEY` (`cartoBasemap.ts`; free at https://carto.com/basemaps/apikey) or CARTO overlays a "KEY REQUIRED" watermark. Live tracker vector styles (MapLibre `style.json`) do not use this key.
- Shipping for Admin: Phase 2 **Shippo** admin Buy label on Fly (`SHIPPO_API_TOKEN` server-side only) after Stripe payment; paste tracking remains as fallback. No Pirate Ship account. Checkout still uses 25% shop USPS / tracker FREE. Mobile shop catalog/cart remain largely client-side. See `docs/backend/specs/shippo-labels.md`.
- Onboarding service type (Court Ordered / Volunteering / School / Other) syncs to Auth `user_metadata.service_type` and shows in admin Sessions; it is distinct from per-session `sessions.court_ordered` and `court_orders` rows. Mobile session detail shows the admin's volunteer-facing `sessions.decline_reason` when Declined (`admin_notes` admin-only). Paid access is **$59.99 tracker + free cleanup kit** (no free orientation hour). **Pre-track `/tracker-paywall` is hidden** — Track goes straight to session setup (`needsTrackerPaymentBeforeTrack` always false; route kept for later); hide session-onboarding middle screens the same way. When that paywall is re-enabled: **Pay Later** / back returns Home with no new session and bottom nav must show **Home** highlighted; `HomeScreen` hardcodes `activeTab="home"` (do not store tab state on `/` — it stays mounted when Account/Shop/Sessions stack on top). Session-detail footer **Go Home** is a filled tertiary button (no stroke); back chevron also returns Home (not live tracker). Inbox hours-adjusted notices use an **Under review** chip, not Hours. Mobile list/detail fetch uses inline spinner + text; session finalize uses `BrandLoadingView` (Garbagio in the top 75% + cream Sanchez **Saving your session. Meet our mascot, Garbagio, in the meantime!**; plays once, loops only if save is still running), not a bare `ActivityIndicator`. **End Session always finalizes `under_review`** — Fly ignores legacy `skipOrientation` (no auto-approve).
- Admin **Company codes** (`/company-codes`) generates 10-digit single-use codes (`admin/db/029_company_codes.sql`); volunteers redeem on How it works via Fly `POST /company-codes/redeem` (requires a real JWT; confirm before redeem so Cancel does not consume the code; copy: code can only be used once). Create Account stashes a draft only until personal details + under-13 age gate; then Creating → How it works. Welcome / Create Account stay fully visible at the correct height and should not scroll; OAuth callback remains `nonprofitmobileapp://auth/callback`. **Delete Account** (type DELETE) calls Fly `DELETE /users/me` and keeps court-ordered logs.
- **Download Service Record** is the bulk approved-session export: Sessions fixed bottom-right **Export record** FAB (hidden in Select / export mode) enters multi-select — **Export all** (approved gate → date-range PDF/CSV), **Share** (OS sheet for selected), **Cancel**; second link on Account Records (and Privacy). No approved sessions → **No approved sessions to download.** Date range defaults earliest approved → today; PDF is the admin's signed letter + evidence pages; CSV is a spreadsheet of the same sessions. Session-detail **Download PDF** stays for a single approved session; Sessions **Select** is delete-only.
